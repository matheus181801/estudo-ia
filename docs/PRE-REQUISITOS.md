# Pré-requisitos — o que o Matheus precisa ter em mãos

Marque cada item antes de começar. **Nunca cole chaves ou senhas no chat**: elas vão só no arquivo `.env`
(que o Claude Code vai criar a partir do `.env.example`) e, na Fase 7, nas variáveis do EasyPanel.

## No notebook
- [ ] Claude Code instalado e com login feito (`claude` no terminal).
- [ ] Git instalado e conta no GitHub.
- [ ] Livros adquiridos legalmente copiados para `estudo-ia/biblioteca/`.

## Contas e chaves
- [ ] **Gemini API**: chave criada no Google AI Studio. O Gemini TTS e o File Search podem exigir faturamento ativo na conta.
- [ ] **Claude API**: chave criada no Console da Anthropic, com créditos (cobrança por uso, separada da assinatura do Claude).
- [ ] **Bot do Telegram**: criado no @BotFather (guarde o token) e o seu chat_id (o Claude Code mostra como obter).
- [ ] **Gmail**: verificação em duas etapas ativa e uma **senha de app** criada para o envio dos e-mails.
- [ ] **NotebookLM**: conta Google com acesso ao NotebookLM. O login será feito com `notebooklm login` no seu notebook, durante a Fase 4.

## VPS
- [ ] Acesso SSH à VPS (IP, usuário e chave SSH) funcionando a partir do seu notebook.
- [ ] Acesso ao painel do EasyPanel.

## Custos a acompanhar
- Claude API e Gemini API cobram por uso. Configure limites de gasto nos dois consoles antes da Fase 3.
